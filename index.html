A plasma code that conserves energy and runs on GPUs.

ECsim-X is a massively parallel, fully electromagnetic Particle-in-Cell code for space plasma physics. It builds on the Energy-Conserving Semi-Implicit Method (ECsim), parallelized with MPI, and adds GPU acceleration with OpenACC and CUDA.

ECsim-X in CUDA: 9.0× faster than OpenACC on a single JUPITER Booster node

ECsim-X is the first semi-implicit PIC code to scale to 4,096 GPUs.

Implemented in CUDA, it runs 9.0× faster than the OpenACC implementation and 34× faster than the reference CPU version on one JUPITER Booster node. Scaling experiments reach parallel efficiencies of 79.7% on 2,048 GPUs and 78.6% on 4,096 GPUs, where the weak-scaling run simulates 2.9 trillion particles in FP64 precision.

How it works

One linear solve per step, no nonlinear iteration

ECsim computes the particles’ response to the fields analytically and folds it into a linear Maxwell system. The cycle therefore looks like an explicit PIC code, while remaining stable for large time steps and coarse grids.
