Benchmarks from published studies

Scaling, speedup, and energy results reported for the MPI and OpenACC implementations, with their hardware and test conditions.

Data source. Every number on this page is quoted from the published papers listed in the references; none was re-measured for this website. Each result carries its hardware and test conditions. Results for the CUDA implementation are not yet published here.

Node: Intel Xeon Platinum 8358 (32 cores) with four NVIDIA A100 GPUs. Single-node benchmark: 2D current filamentation, 256×128 grid, 4 species, 60×60 particles per cell per species (≈4.72×108 particles), 100 steps. The CPU reference used 32 MPI tasks; the GPU run used 4 tasks, one per A100.

Node-level breakdown

  • Moment gathering was accelerated about 15× and now accounts for 23% of execution time, comparable to the other code blocks.
  • Initialisation and the field calculation stay on the CPU with MPI only and are about 8× slower in this experiment because the GPU run uses four MPI tasks instead of 32.

Energy measurement method

GPU power was sampled with nvidia-smi and CPU energy with perf stat, both over the simulation phase only; RAM, disk and network were excluded. CPU energy remains non-negligible in accelerated runs.

Reporting your own results

  1. Record source revision, compiler, flags, dependencies, and precision.
  2. Record hardware, device count, CPU topology, and interconnect.
  3. Specify grid, particles per cell, time step, θ, and output frequency.
  4. Separate initialisation, time step, I/O, and total runtime.
  5. Repeat measurements and report a defined statistic and variability.
  6. Verify energy and physical diagnostics for every configuration compared.
