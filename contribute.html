Scientific collaboration

How to contribute

Contributions should improve the scientific reliability, usability, documentation, or performance of ECsim-X. The project’s official distribution and maintainer guidance take precedence over the general recommendations on this page.

Public availability is not the same as an open-source license. Please check the terms distributed with ECsim-X before redistributing code, modifying it for external distribution, or incorporating it into another project.

Useful contributions

  • Report reproducible simulation errors or unexpected numerical behavior.
  • Improve user documentation, input descriptions, and examples based on verified behavior.
  • Provide scientifically justified validation cases and comparisons with established results.
  • Report performance observations with the hardware, compiler, configuration, and measurement procedure recorded.
  • Suggest usability improvements or corrections to the website.

Before proposing a change

  1. Check the distributed documentation and existing issue or discussion channels, where available.
  2. Describe the scientific or practical motivation and the expected outcome.
  3. For numerical issues, include the smallest reproducible case, relevant input settings, diagnostics, and expected versus observed behavior.
  4. For performance reports, record hardware, software versions, problem size, and measurement conditions.

Review and validation

Changes that affect the numerical method or simulation results should include a clear explanation of the scientific rationale and suitable validation evidence. Performance changes should be checked for numerical consistency as well as runtime. Documentation changes should be consistent with behavior observed in the distributed application.

Where to submit

Official contribution channel needed Add the verified project repository, issue tracker, maintainer contact, or other official channel here. Until that information is available, this page does not imply that pull requests or public issue submissions are enabled.

Working together

All participants are expected to communicate respectfully and constructively. See the Code of Conduct for the standards expected in project-related interactions.
