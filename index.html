Energy-conserving plasma kinetics.
Accelerated on GPUs.

ECsim-X is a massively parallel, fully electromagnetic Particle-in-Cell code for space plasma physics. It builds on the Energy-Conserving Semi-Implicit Method (ECsim), parallelized with MPI, and adds GPU acceleration.

How it works

One linear solve per step, no nonlinear iteration

ECsim computes the particles’ response to the fields analytically and folds it into a linear Maxwell system. The cycle therefore looks like an explicit PIC code, while remaining stable for large time steps and coarse grids.
