About ECsim-X

A massively parallel, energy-conserving semi-implicit Particle-in-Cell code with GPU acceleration, developed on the ECsim method.

Project overview

ECsim-X is a massively parallel, fully electromagnetic Particle-in-Cell code for space plasma physics. It implements the Energy-Conserving Semi-Implicit Method (ECsim) with GPU acceleration. ECsim itself is a C/C++ code parallelized with MPI; ECsim-X adds an OpenACC GPU implementation, and a CUDA implementation that has been evaluated on JUPITER Booster (see Benchmarks).
